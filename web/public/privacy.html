Privacy

This local distribution stores player names, email addresses, password hashes, messages, gameplay state, session data, IP records, and operator logs in its MariaDB, Redis, runtime, and backup volumes.

No payment, analytics, newsletter, Telegram, hosted help, or third-party email service is enabled. Authenticated players can schedule account deletion in the game options. Self-service export is not yet implemented, so an operator must handle export requests.

Deleting containers does not erase volumes or separate backups. Do not expose this release publicly without operator contact details, exact retention periods, a jurisdiction-appropriate privacy policy, and independent review. See the repository privacy documentation for the full inventory.
