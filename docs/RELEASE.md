# Release readiness

## Current classification

OpenVillage is a local/private-play preservation alpha. It is suitable for
development, archaeology, and small trusted local games on the supported
Docker profile. It is not approved for payments or an unattended public server.

## Verified scope

- one-command container build and installation;
- versioned forward migrations;
- health and readiness checks;
- registration, activation, tribe/sector selection, and village creation;
- fresh login and core authenticated pages;
- deterministic ruleset timers, map boundaries, password migration, and World
  Wonder second-plan semantics;
- a golden combat fixture and supported-profile resource, unit, and storage
  formulas;
- isolated clean installation, forward migrations, backup, and restore;
- PHP and JavaScript syntax, application logs, and public-repository hygiene;
- localhost-only default exposure and disabled payments/hosted integrations.

## Gates before 1.0

- deterministic complete-round coverage through a player World Wonder level 100;
- construction, training, conquest, hero, artifact-capture, Natar, and
  crash/retry fixtures;
- replacement or qualified review of legacy visual, audio, and translated assets;
- self-service account export and verified account deletion;
- public-host deployment controls, observability, load tests, and runbooks;
- independent legal and security review.

Security scanning is intentionally not part of the current finishing pass. It
remains a gate before recommending public exposure.
